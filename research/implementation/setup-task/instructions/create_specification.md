# Write a task specification

Fill [`../TASK_TEMPLATE.md`](../TASK_TEMPLATE.md) from the research question.
Read [`task_quality_objectives.md`](task_quality_objectives.md) first.

Resolve ambiguity before coding: enumerate variables and values, state how every
intermediate contributes to the output, list accepted surface forms, and define
what each counterfactual generator changes and holds fixed. Keep real uncertainty
visible in the specification rather than filling gaps with guessed mechanisms.

Choose the closest shipped task package and name it in the specification. Explain
the differences that require new code.
